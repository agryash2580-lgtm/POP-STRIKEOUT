# Supplied frontend provenance

The desktop visual shell was supplied by the project owner in `yash.zip`.
Its supplied README refers to `Krishnanshu06/yash`, and the frontend package
identifies a Figma Make export. These are retained provenance notes, not a
claim that STRIKEOUT's team originally authored that supplied visual shell.

STRIKEOUT integration adds the authenticated case workspace, report UI,
evidence handling, backend connection, real status and extension integration.
Third-party dependency licences remain applicable. No permission or licence
grant for the supplied shell has been independently established here.

The unused configuration for a different Firebase project was disconnected.
Simulated security-monitor claims were replaced with actual service status.
